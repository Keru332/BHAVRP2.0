\chapter*{Resumen}

El Problema de Planificación de Rutas de Vehículos con Múltiples Depósitos (MDVRP) constituye una variante compleja dentro de los problemas de optimización combinatoria. En la práctica, este problema suele resolverse dividiéndolo en dos etapas: asignar los clientes a los depósitos y construir las rutas desde cada depósito. La Biblioteca de Heurísticas de Asignación para Problemas de Planificación de Rutas de Vehículos con Múltiples Depósitos (BHAVRP) es un componente de software dise\~nado para resolver esta primera fase de asignación. La biblioteca presenta una arquitectura modular que encapsula algoritmos de agrupamiento clasificados en particionales, jerárquicos y basados en densidad, incluye un sistema de tratamiento de excepciones y un conjunto de métricas de evaluación internas. Actualmente, BHAVRP  cuenta con un solo algoritmo de agrupamiento basado en densidad. Se propone la incorporación de un nuevo algoritmo de agrupamiento basado en densidad HDBSCAN. Este algoritmo de agrupamiento es adaptado para resolver la fase de asignación de clientes a depósitos incorporando restricciones de capacidad de los depósitos y mecanismos de asignación controlada usando como base la implemetación de la biblioteca JSAT. Por último, se realiza un estudio experimental que permite garantizar el correcto funcionamiento de los módulos implementados, así como realizar un análisis de correlación entre las metricas internas y las rutas obtenidas por los clústeres. Para ello, se utilizan los criterios definidos por las métricas de evaluación que ya tiene BHAVRP y la Biblioteca de Heurísticas de Construcción para Problemas de Planificación de Rutas de Vehículos (BHCVRP).

\vspace{12pt}
\noindent\textbf{Palabras clave:} algoritmos de agrupamiento, BHAVRP, HDBSCAN, MDVRP.

\chapter*{Abstract}

The Multi-Depot Vehicle Routing Problem (MDVRP) constitutes a complex variant within combinatorial optimization problems. In practice, this problem is often solved by dividing it into two stages: assigning customers to depots and building routes from each depot. The Assignment Heuristics Library for Multi-Depot Vehicle Routing Problems (BHAVRP) is a software component designed to solve this first assignment phase. The library features a modular architecture that encapsulates clustering algorithms classified into partitional, hierarchical, and density-based, includes an exception handling system, and a set of internal evaluation metrics. Currently, BHAVRP has only one density-based clustering algorithm. The incorporation of a new density-based clustering algorithm, HDBSCAN, is proposed. This clustering algorithm is adapted to solve the customer-to-depot assignment phase by incorporating depot capacity constraints and controlled assignment mechanisms, using the implementation from the JSAT library as a basis. Finally, an experimental study is conducted to ensure the correct functioning of the implemented modules, as well as to perform a correlation analysis between the internal metrics and the routes obtained by the clusters. For this purpose, the criteria defined by the evaluation metrics already present in BHAVRP and the Construction Heuristics Library for Vehicle Routing Problems (BHCVRP) are used.

\vspace{12pt}
\noindent\textbf{Keywords:} BHAVRP, clustering algorithms, HDBSCAN, MDVRP.
